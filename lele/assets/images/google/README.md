# Google "G" logo

`g_logo.png` (and its 2.0x/3.0x density variants) is Google's official
"G" mark, downloaded unmodified from
<https://developers.google.com/identity/images/g-logo.png> — the asset
Google publishes for the "Sign in with Google" button.

Per <https://developers.google.com/identity/branding-guidelines> the logo
must be used as supplied: it may not be recreated, recoloured, rendered in
monochrome, or distorted. The only processing applied here is scaling to
Flutter's density buckets, with the glyph's aspect ratio preserved and
centred on a square transparent canvas.

Do not hand-edit these files. To refresh, re-download the source above and
re-run the scaling described in this note.
